# 电位器（模拟旋钮）Mind+ 扩展库

版本 1.0.0，适用于 **Mind+ 1.x → 上传模式 → Arduino Uno / Uno R3、掌控板**。此库独立于旋转编码器库，扩展 id 为 `potentiometer`。不适用于 Mind+ 2.x 的扩展接口。

用户已确认照片中的模块是一个 **3P S/V/G 接口**。S 是模拟信号，V 是电源，G 是地。电位器读的是当前旋钮位置对应的模拟值，没有累计圈数或按下归零功能。

## 接线

| 模块引脚 | Uno 默认接线 | 掌控板默认接线 |
|---|---|---|
| S | A0 | P0 |
| V | 5V（模块须支持） | 3.3V（模块须支持） |
| G | GND | GND |

按模块上的字母标识接线，不以照片方向或线色判断。掌控板不能输入 5V 信号；连接掌控板时使用 3.3V 供电并确保模块输出不超过 3.3V。如果该模块仅支持 5V，需要合适的信号电平转换。

Uno 可选 A0～A5。掌控板可选 P0 / P1 / P2 / P3，对应 GPIO33 / GPIO32 / GPIO35 / GPIO34；菜单显示板上 P 编号，代码使用实际 GPIO。选用这些 ADC1 脚，避免占用板载光线/麦克风和 ADC2。与编码器同时使用时，各信号脚不能重复；例如编码器用 P0/P1/P8，电位器改用 P2。

## 导入

开发目录：`sensors/potentiometer/`。分享目录：`releases/potentiometer/`。

1. 在 Mind+ 选择上传模式和 Uno 或掌控板。
2. 打开“扩展 → 用户库 → 从本地导入”。
3. 选择本库的 `config.json`，旁边的 arduinoC 文件夹需完整保留。
4. 如果收到的是 ZIP，先在资源管理器解压，再导入里面的 config.json；Mind+ 文件选择框通常不显示 ZIP。

库名称为“电位器（模拟旋钮）”，使用无文字卡通硬件封面。封面由内置 image_gen 根据用户照片制作，提示词见 `assets/cover-prompt.txt`。

## 最简单的 Uno 积木程序

```text
当开始运行
    设置串口波特率为 115200
    初始化电位器 模拟信号 S 接 [A0]

重复执行
    串口打印 [电位器百分比（0～100）] 并换行
    等待 [0.1] 秒
```

把椭圆形的“电位器百分比（0～100）”积木拖入串口打印输入框。上传后，打开串口监视器，波特率设为 115200；旋转电位器查看 0～100 的变化。

掌控板只需把初始化引脚改为 P0，也可使用掌控板 OLED 积木显示百分比。硬件旋钮有行程限制时，不要强行越过端点。

可直接打开的 Mind+ 项目：

- [Uno A0 百分比示例](examples/MindPlus/电位器_Uno_A0_百分比示例.mp)：A0 输入，串口 115200，每 0.1 秒打印百分比；按本机原生 .mp 结构生成，内嵌本库，已检查块连接和资源完整性，尚未做界面打开验收。
- [用户保存的原始示例](examples/MindPlus/电位器示例程序.mp)：保留原样，S 接 A3，串口输出原始读数；未设置波特率积木，使用 Mind+ 默认串口配置。

仓库和发布 ZIP 仅提供上述 Mind+ `.mp` 示例；Arduino 验证草图仅在开发者本地保留。

## 10 个积木

| 积木 | 用法 |
|---|---|
| 初始化电位器 模拟信号 S 接… | 开始运行时执行一次；恢复默认方向、8 次采样和完整 ADC 量程。 |
| 电位器初始化成功？ | 判断引脚配置是否有效；不能检测模块是否插入或线路是否断开。 |
| 电位器原始读数 | Uno 为 0～1023，掌控板为 0～4095；默认返回 8 次采样的四舍五入均值，不受校准或反转影响。 |
| 电位器百分比（0～100） | 按配置的量程换算为整数百分比，自动限制在 0～100。 |
| 电位器映射到…至… | 例如 0～255 控制亮度，0～180 作为舵机指令；返回数值，可含小数，支持负数及反向输出范围。 |
| 电位器原始量程上限 | Uno 返回 1023，掌控板返回 4095，未初始化也可读取。 |
| 电位器平均采样次数… | 1 / 4 / 8 / 16 / 32，默认 8；次数越多，平均耗时越长。 |
| 电位器数值方向 正常/反转 | 仅反转百分比和映射值；希望顺时针增大但实际相反时使用。 |
| 电位器校准 原始最小值…原始最大值… | 将实际测得的旋转两端读数设为百分比的 0% 和 100%；最小必须小于最大。 |
| 电位器恢复默认量程 | 恢复 0～1023 或 0～4095，不改变方向和采样次数。 |

每次读取原始值、百分比或映射值时都会进行新采样，不需要“更新”积木。若同一轮需要完全一致的数值，把一次读数先保存到变量中再使用。平均采样可减小波动，但不保证最后一位始终不跳。

映射积木只是数值换算，不直接驱动 LED 或舵机，也不等于测出了真实物理角度或电压。无有效初始化时，原始值和百分比返回 0，映射返回设置的输出下限。

## 端点校准

先用串口显示“电位器原始读数”，将旋钮转到两端，分别记录稳定读数中的较小值、较大值。在初始化后加入校准积木，填入这两个数。积木中的 100、900 只是示例默认值，不是这块模块的出厂参数；初次使用无需加校准积木。

例如 Uno 实际两端读数为 8、1010，就填 8 和 1010。小于下端的值限制为 0%，大于上端的值限制为 100%。无效范围（负数、相等、颠倒或超过主控量程）会被忽略并保留原配置。校准参数保存在 RAM；需要每次启动生效时，将校准积木放在初始化之后。

掌控板 ADC 默认采用 12 位采样和 11dB 衰减；端点可能提前饱和，量程也不保证与电压严格线性。校准可以对齐两端，不能校正 ADC 全程非线性。本库不提供精密电压测量。参见 [Espressif ADC 文档](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/adc.html)。

## 开发与兼容性

本库不占用中断或定时器。图形积木使用一个电位器对象；C++ 可按需要创建多个对象，但每次采样应在主循环顺序调用。

掌控板每次读取都会重新设为 12 位分辨率和当前引脚的 11dB 衰减，因为 Mind+ 或其他库可能改变 ADC 配置。这些设置会影响共享的 ADC，其他代码若依赖不同分辨率，应在自身读取前重新设置。Uno 不主动更改 analogReference，示例按默认参考电压使用。

引脚定义与 API 已核对本机 Mind+ 自带 mpython 核心，结构依据 [Mind+ 1.x 扩展规范](https://mindplus.dfrobot.com.cn/ext-api)。封面尺寸为 600×372。

在工作区根目录执行 `python tools/package.py potentiometer` 生成分享包；独立解压后也可运行本库 `tools/package.py`，默认输出到本库 dist。验证记录见 `VALIDATION.md`。
